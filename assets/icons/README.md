# Transom icon (PLACEHOLDER)

These files are a **placeholder**, not Transom's final icon. The owner decided on 2026-10-19 that
Transom gets its own icon (a window with a transom bar above it), not Sill's; the final artwork
still has to be drawn and approved. Replace every file here with the final design, keeping the
names and sizes.

- `transom.svg`: the source, a 512×512 canvas.
- `transom-16.png` … `transom-512.png`: the same drawing at 16, 32, 48, 64, 128, 256 and 512 px
  (Linux icon theme sizes; the 64 px one is also the runtime window icon).

Colours are the app's palette (docs/ui-spec.md section 3.1): #23262C control, #9BB7FF accent,
#EEF0F3 text, #2C3550 control open.
